# Minor Project 5 – Sales Operations Analytics

## Project Overview

**Minor Project 5 – Sales Operations Analytics** is an Excel-based data analysis project designed to analyze sales operations, customer information, products, orders, and sales-representative performance.

The completed workbook performs data lookup, data cleaning, aggregation, pivot-style analysis, and advanced business analysis using the provided sales dataset.

## Objectives

- Analyze sales orders and revenue.
- Connect orders with customer, product, and sales-representative information.
- Identify and handle data-quality issues.
- Calculate important sales metrics.
- Compare performance across regions, categories, months, and sales representatives.
- Use Excel formulas, helper columns, and pivot-style analysis to generate business insights.
- Answer all questions provided in the Minor Project 5 task sheet.

## Workbook Contents

The completed Excel workbook contains the following major analysis areas:

1. **Lookup Analysis**
   - Customer, product, region, category, and sales-representative information.
   - Lookup-based calculations and validation.

2. **Data Cleaning**
   - Duplicate order identification.
   - Invalid/missing references.
   - Discontinued SKU checks.
   - Cancellation and discount validation.
   - Data-quality helper columns.

3. **Aggregation**
   - Total sales/revenue.
   - Order counts.
   - Customer and product-level summaries.
   - Regional and category-level calculations.

4. **Pivot / Business Analysis**
   - Region × Category analysis.
   - Month × Sales Representative analysis.
   - Revenue and order comparisons.
   - Sales performance summaries.

5. **Advanced Analysis**
   - Sales-representative ranking.
   - Additional performance indicators.
   - Exception and data-quality analysis.
   - Business-oriented insights derived from the dataset.

## Key Data-Quality Findings

The completed analysis identified several important issues in the source data:

- **20 duplicate Order IDs**
- **30 orders with broken/invalid customer references**
- **174 orders associated with discontinued SKUs**
- **58 cancelled orders with discounts above 20%**

These findings are included in the completed workbook and can be used to demonstrate the importance of data cleaning before business analysis.
